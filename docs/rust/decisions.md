# 3.0 결정 기록

Ugurugu 3.0(Rust)의 설계 결정과 2.2.13(C++)과 일부러 다르게 한 점을 지금 상태로 모은다. 결정을 바꾸면 해당 행을 고친다. 바뀐 과정과 옛 마일스톤 계획(`docs/RUST_WINDOWS_PORT_PLAN.md`, `docs/rust/m0-close.md`, `m2-plan.md`~`m6-plan.md`)은 git 이력에 있고, 그 문서들이 남은 마지막 커밋은 `70f9454`다.

- 측정값은 [evidence.md](evidence.md)에 있다. 여기서는 "evidence.md의 <주제>"로 가리킨다.
- 연산 의미와 `.ugurugu` 스키마는 [adr-operations-and-format.md](adr-operations-and-format.md), `.ugu` 가져오기는 [ugu-import.md](ugu-import.md), 제품 범위는 [scope.md](scope.md)에 있다.
- **출처**는 옛 문서의 번호다: `port N`은 옛 포팅 계획의 절, `M5-17`은 작업 행, `m6 2절 24`는 그 계획 2절 결정 표의 번호. 코드 주석은 이 파일의 절 제목과 출처 번호로 가리킨다.
- **2.2.13** 열의 "같음"은 2.2.13을 그대로 옮긴 결정, "—"는 해당 없음이다. 확인하지 못한 주장은 **가설**로 적는다.
