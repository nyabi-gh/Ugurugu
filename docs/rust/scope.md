# Rust 3.0 범위

3.0에 무엇이 들어가고 빠지는지, 지원 플랫폼과 하드웨어를 적는다. 왜·어떻게 그렇게 했는지와 2.2.13과 다른 점은 [decisions.md](decisions.md), 측정은 [evidence.md](evidence.md)에 있다. 처음 판(2026-10-06)부터의 변화는 git 이력에 있다.

상태 표기: **확정**(사용자 결정 또는 구현·시험 완료), **보류**(장치 확보 뒤 결정), **열린 gate**(구현했지만 실제 장치로 확인하지 않음, 통과로 적지 않음).

## 1. 측정·개발 환경

| 항목 | 값 |
|---|---|
| OS | Windows 11 Pro x64 (10.0.26300) |
| CPU / RAM | Intel Core Ultra 7 270K Plus / 32GB (31.3GiB 인식) |
| 주 모니터 | 3840×2160, 150%(144 DPI), 23~160Hz(측정은 대부분 160Hz), NVIDIA GeForce RTX 5080 |
| 보조 모니터 | 2560×1440, 155Hz, 100%(96 DPI), Intel Graphics iGPU |
| 입력 | 마우스만. 펜·터치 장치 없음 |
| Rust | 1.99.0 stable, `x86_64-pc-windows-msvc`, edition 2024 (`rust-toolchain.toml`로 고정) |

두 모니터가 서로 다른 GPU에 연결돼 있어, 모니터를 옮길 때의 DPI 변경과 다른 어댑터로 넘어가는 경우를 이 PC에서 시험한다. 앱은 어댑터를 고를 수 없어 Intel iGPU로는 시험하지 못했다. 깨끗한 설치·합성 펜·터치 시험은 이 PC의 Windows Sandbox에서 한다.

## 2. 펜·터치 없이 진행하는 방식

입력 경로는 처음부터 Win32 Pointer API(`WM_POINTER*`)이고 마우스도 같은 경로를 쓴다. 장치가 있어야만 확인되는 항목은 통과로 적지 않는다.

| 항목 | 마우스 | 합성 입력(Sandbox) | 실제 장치 |
|---|---|---|---|
| sample history 정렬·중복·유실 | 확인 | 확인(1000개/초) | 열린 gate |
| capture, 창 밖 버튼 해제, Alt+Tab, 포커스 상실 | 확인 | 창 밖 해제 확인 | 열린 gate |
| DPI가 다른 모니터 이동 | 확인 | — | — |
| 필압·유효성 mask | 경로만(압력 없음으로 보고) | 압력 곡선 확인 | 열린 gate |
| hover, barrel button | — | 확인 | 열린 gate |
| 펜 지우개 끝 | — | Windows가 합성 플래그를 넘기지 않아 단위 시험 | 열린 gate |
| 터치 팬·핀치·회전 | — | 확인 | 열린 gate |
| WinTab | — | — | 보류 |

실제 장치 gate는 3.0 출시를 막지 않는다. 사용자가 태블릿으로 압력·지우개 끝·barrel·hover·두 손가락 제스처를 확인하면 닫고 릴리스 노트의 펜 문장을 고친다.

## 4. 플랫폼과 하드웨어

| 항목 | 범위 |
|---|---|
| OS | Windows x64. Windows 11에서 시험한다. Windows 10은 막지 않고 README의 "Windows 10 이상"을 둔다(따로 시험하지 않음, 2026-10-11 사용자 결정) |
| ARM64 | 제외 |
| macOS | 3.0 출시 범위에서 빼고 3.0 뒤에 지원한다(2026-10-10 사용자 결정). 그때까지 macOS는 2.2.13 |
| GPU | 하드웨어 DX12 어댑터. 표시할 수 없으면 WARP(느린 소프트웨어 표시)로 연다. 시험한 것은 RTX 5080과 WARP이고, 다른 GPU는 열린 gate |
| 원격 세션 | Windows Sandbox 원격 세션에서 실행·업데이트·WARP 확인. 다른 PC에서 `mstsc`로 접속한 경우는 미확인 |
| 설치 | 사용자 단위(관리자 권한 없음), 2.2.13과 함께 설치 가능 |

## 5. 제외

- 구형 `.ugu` schema 1~12·`.wagle`·`.wobble`·`.wawa`·`.wwpreset` 읽기("지원하지 않는 형식" 판별과 "2.2.13에서 다시 저장" 안내만).
- 이전 설정·프리셋·복구본 이관, Qt 클립보드 형식, `.ugu` 파일 연결.
- 모바일·웹(WASM·Svelte), C++ 엔진 FFI.
- 2.2.13에도 없던 것: 최근 파일 메뉴(작업 표시줄 Jump List는 backlog B3-66), 팔레트 파일, GIF·WebP 손실 압축·디더·프레임 범위, 고정·색 수 제한 팔레트, 직선·도형 도구(요청은 backlog B3-99), 다시 편집할 수 있는 문자 객체, 교집합 선택.
- 자동 충돌 보고 전송, 델타 업데이트, 코드 서명(출시 뒤 다시 볼 수 있음).
- "그리는 동안에도 우글거림 유지" 선택지, 수치 변형 대화상자(변형 상자로 대신함).
