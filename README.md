선을 긋기만 하면 손그림 애니메이션처럼 살아서 꿈틀거립니다.
움직이는 그림은 GIF나 WebP로 저장해 어디든 올릴 수 있어요.

> [!NOTE]
> Ugurugu 3.0은 Windows 전용입니다. macOS에서는 2.2.13을 써 주세요.
> 2.x에서 만든 `.ugu` 파일은 3.0에서 그대로 열 수 있습니다.

## 다운로드

| 플랫폼 | 지원 환경 | 다운로드 |
| --- | --- | --- |
| Windows | Windows 10 이상, 64비트 | [Setup.exe](https://github.com/nyabi-gh/Ugurugu/releases/latest/download/Ugurugu-Windows-x64-Setup.exe) |
| macOS (2.2.13) | macOS 14 이상, Apple Silicon | [DMG](https://github.com/nyabi-gh/Ugurugu/releases/download/v2.2.13/Ugurugu-macOS-arm64.dmg) |

설치할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
파일은 꼭 [공식 릴리스 페이지](https://github.com/nyabi-gh/Ugurugu/releases/latest)에서
받아 주세요.

## 처음 시작하기

1. 브러시를 골라 선을 그립니다.
2. **우글거림** 패널에서 움직임을 고르고 `P`를 눌러 재생합니다.
3. **파일** 메뉴에서 GIF나 WebP로 내보냅니다.

모르는 게 있으면 `F1`을 눌러 도움말을 보세요.

## 이런 걸 할 수 있어요

- **우글거림** — 움직임의 세기와 느낌을 고르고, 레이어마다 따로 움직이거나 멈출 수 있습니다.
- **그리기** — 펜·마커·에어브러시·스프레이 브러시와 필압, 선택과 변형, 글자.
- **픽셀 아트** — 픽셀 모드로 또렷한 도트 그림을 그리고 크게 키워 내보낼 수 있습니다.
- **여러 그림을 탭으로** — 한 창에서 여러 그림을 오가며 작업합니다.
- **내 마음대로** — 패널 배치, 밝은·어두운 테마, 단축키를 바꿀 수 있고, 갑자기 꺼져도 작업을 되살립니다.

설정은 **편집 → 설정**(`Ctrl+,`)에 있습니다.

## 자주 쓰는 단축키

| 키 | 동작 |
| --- | --- |
| `B` / `E` | 브러시 / 지우개 |
| `P` | 재생 / 일시정지 |
| `Space` + 드래그, 스크롤 | 캔버스 이동, 확대·축소 |
| `Ctrl+Z` / `Ctrl+Y` | 실행 취소 / 다시 실행 |
| `I` 또는 `Alt` + 클릭 | 색 가져오기 |

단축키는 **설정 → 단축키**에서 모두 바꿀 수 있습니다.
