그림이 우글우글 움직이는 드로잉 앱입니다.

완성한 그림은 반복 재생되는 GIF나 WebP, 배경이 투명한 이미지로 저장할 수
있습니다. WiggleWiggleTool에서 만들던 `.wawa` 그림도 이어서 작업할 수
있습니다.

> [!NOTE]
> 문제가 생겼다면
> [GitHub 이슈](https://github.com/nyabi-gh/Ugurugu/issues)에
> 어떤 작업을 했는지와 실제로 일어난 일을 적어 주세요. 가능하면 `.ugu`
> 파일도 함께 보내 주시면 원인을 찾는 데 큰 도움이 됩니다.
>
> 다만 보안 취약점은 공개 이슈 대신
> [보안 정책](SECURITY.md)에 적힌 비공개 경로로 알려 주세요.

## 다운로드와 설치

| 플랫폼 | 지원 환경 | 다운로드 |
| --- | --- | --- |
| Windows | Windows 10 이상, 64비트 | [Windows 설치 파일](https://github.com/nyabi-gh/Ugurugu/releases/latest/download/Ugurugu-Windows-x64-Setup.exe) |
| macOS | macOS 14 이상, Apple Silicon | [macOS 설치 파일](https://github.com/nyabi-gh/Ugurugu/releases/latest/download/Ugurugu-macOS-arm64.dmg) |

### Windows

다운로드한 Setup 파일을 실행하세요. Windows에서 출처 확인 경고가 나오면
**추가 정보 → 실행**을 누르면 됩니다. 안전을 위해 반드시 공식
[Releases 페이지](https://github.com/nyabi-gh/Ugurugu/releases/latest)에서
받은 파일만 사용하세요.

### macOS

DMG를 열고 Ugurugu를 Applications 폴더로 드래그하세요. macOS용
앱은 Apple의 확인을 거쳐 배포됩니다.

릴리즈 페이지에 보이는 다른 파일은 자동 업데이트에 필요한 파일입니다.
일반 사용자는 위 표의 설치 파일만 받으면 됩니다.

## 시스템 사양

| 항목 | 최소 사양 | 권장 사양 |
| --- | --- | --- |
| 운영체제 | Windows 10 64비트 / macOS 14 (Apple Silicon) | Windows 11 / 최신 macOS |
| 메모리 | 8GB | 16GB 이상 |
| 그래픽 | 별도 요구 없음 | Direct3D 11(Windows) 또는 Metal(macOS)을 지원하는 GPU |
| 입력 장치 | 마우스 | 필압을 지원하는 펜 태블릿 (Wacom 등) |

캔버스 표시와 확대·이동·재생은 GPU 가속으로 처리되며, 그래픽 가속을
사용할 수 없는 환경에서는 소프트웨어 렌더링으로 자동 전환됩니다. 큰
캔버스(최대 4096×4096)에 레이어를 여러 장 두고 작업한다면 메모리가
넉넉할수록 미리보기가 매끄럽습니다.

## 처음 시작하기

1. 앱을 열고 새 캔버스를 만들거나 기존 그림을 엽니다.
2. 왼쪽에서 브러시를 고르고 선을 그립니다.
3. **우글거림** 패널에서 움직임을 고른 뒤 `P`를 눌러 재생합니다.
4. **파일** 메뉴에서 움직이는 GIF·WebP 또는 PNG·JPG 이미지로 내보냅니다.

`F1`을 누르면 언제든 앱 안에서 간단한 사용법을 볼 수 있습니다.

## 무엇을 할 수 있나요?

### 선을 내 취향대로 움직이기

- 부드럽게 이어지는 움직임, 툭툭 끊어지는 움직임, 익숙한 기본 움직임 중
  하나를 고를 수 있습니다.
- 흔들리는 정도와 움직임의 촘촘함, 선들이 함께 움직이는 정도, 무작위 느낌을
  조절할 수 있습니다.
- 중간중간 끊긴 선을 만들거나 지우개 자국도 함께 움직이게 할 수 있습니다.
- 움직임을 끄면 일반 그림 앱처럼 사용할 수 있습니다.

#### 우글거림 설정 자세히 보기

**우글거림** 패널에서 아래 값들을 조절할 수 있습니다. 패널 위쪽의 범위를
**활성 레이어**로 바꾸면 선택한 레이어에만 적용됩니다.

| 설정 | 범위 (기본값) | 설명 |
| --- | --- | --- |
| 모션 스타일 | 클래식 · 부드럽게 · 단계별 (클래식) | 움직임을 만드는 방식입니다. **클래식**은 이전 버전과 같은 익숙한 움직임이고, **부드럽게**는 포즈와 포즈 사이를 이어서 흐르듯 움직이며, **단계별**은 포즈를 툭툭 갈아 끼워 손그림 애니메이션 같은 느낌을 줍니다. |
| 흔들림 | 0 ~ 12 px (1.6 px) | 선이 원래 자리에서 최대 얼마나 벗어날지입니다. 0으로 두면 움직이지 않습니다. |
| 포즈 수 | 1 ~ 프레임 수 (8) | 우글거림이 돌려 쓰는 **서로 다른 그림의 개수**입니다. 30프레임에 포즈 8이면 8장을 그려 반복하는 셈입니다. 적을수록 뚝뚝 끊기는 손그림 느낌이 나고, 많을수록 매끄럽습니다. **1로 두면 완전히 멈춥니다.** |
| 디테일 | 1 ~ 24 (12) | 선을 따라 생기는 흔들림의 **간격**입니다. 낮으면 크고 완만한 물결이 되고, 높으면 잘게 떠는 느낌이 됩니다. |
| 연결 | 0 ~ 100% (100%) | 선들이 **얼마나 한 몸처럼 움직이는지**입니다. 100%면 그림 전체가 한 장처럼 같은 방향으로 흔들리고, 0%면 선마다 제각각 움직입니다. |
| 무작위성 | 0 ~ 100% (0%) | 0%면 부드럽게 흐르는 움직임이고, 100%로 올릴수록 점마다 튀는 지글지글한 노이즈가 됩니다. |
| 끊어진 선 | 켬 · 끔 (끔) | 켜면 선의 일부가 사라졌다 나타났다 합니다. 아래 두 값은 이걸 켜야 적용됩니다. |
| 끊김 정도 | 0 ~ 100% (35%) | 선이 사라지는 **양**입니다. 0%면 안 끊기고, 100%면 선이 통째로 사라집니다. |
| 끊김 범위 | 2 ~ 256 px (24 px) | 끊기는 **덩어리의 크기**입니다. 작으면 점선처럼 잘게, 크면 뭉텅뭉텅 끊깁니다. |

> [!TIP]
> **포즈 수**와 **디테일**은 모션 스타일이 *부드럽게* 또는 *단계별*일 때만
> 적용됩니다. *클래식*은 두 값을 사용하지 않습니다.

### 편하게 그리고 색칠하기

- 필압을 지원하는 브러시와 지우개, 펜·마커·에어브러시·스프레이 등
  17가지 기본 도구가 준비되어 있습니다.
- 손떨림 보정으로 천천히 그은 선이나 긴 선을 더 매끄럽게 만들 수 있습니다.
- 지원되는 멀티터치 화면에서는 두 손가락으로 캔버스를 옮기고 확대·축소·회전할
  수 있습니다.
- 페인트 통은 비슷한 색의 범위를 조절하고, 현재 레이어만 볼지 다른 레이어도
  함께 볼지 선택할 수 있습니다.
- 자유형·사각형·타원으로 영역을 고른 뒤 이동, 크기 변경, 회전, 뒤집기,
  복사와 붙여넣기를 할 수 있습니다.
- 영역을 고르는 대신 둘러싼 모양을 바로 색칠하는 방법도 지원합니다.

### 레이어와 이미지 다루기

- 레이어를 순서대로 쌓거나 그룹으로 묶고, 투명도와 겹침 효과를 바꿀 수
  있습니다. 목록에서 각 레이어의 불투명도와 합성 모드를 바로 확인할 수
  있습니다.
- 레이어마다 우글거림을 끄고 켤 수 있습니다. 배경은 멈춰 두고 그 위의 선만
  움직이게 만들 수 있습니다.
- 모양이 달라지지 않는 경우에만 아래 레이어와 안전하게 합칠 수 있습니다.
- 사진이나 다른 그림을 새 레이어로 넣고 이동, 크기 변경, 회전할 수 있습니다.
  여러 번 크기를 바꿔도 원본을 기준으로 보여 줍니다.
- 캔버스를 자르거나 넓힐 수 있고, 그림 전체 크기도 바꿀 수 있습니다.

### 저장하고 공유하기

- 작업 파일은 `.ugu`로 저장되며 레이어와 움직임 설정을 그대로 보관합니다.
- 이전 버전에서 만든 `.wagle`과 `.wobble` 파일도 그대로 열립니다.
- 움직이는 GIF와 WebP, 한 장의 PNG와 JPG로 내보낼 수 있습니다.
- 투명한 배경을 사용하면 스티커처럼 배경 없는 이미지와 애니메이션을 만들 수
  있습니다.
- 자주 쓰는 브러시·색칠·우글거림 설정은 `.wwpreset` 파일로 저장해 다른
  컴퓨터에서도 불러올 수 있습니다.
- 비정상적으로 종료되어도 다음 실행 때 작업을 복구할 수 있습니다.

### 내게 맞게 바꾸기

- 패널은 원하는 자리로 끌어다 놓을 수 있습니다. 다른 패널의 **위나 아래**로
  끌면 세로로 쌓이고, **좌우 가장자리**로 끌면 옆에 나란히 붙어 2단이 됩니다.
  제목줄 위로 끌면 탭으로 묶입니다.
- 오른쪽·왼쪽 패널 전체를 버튼 하나로 접어 화면을 넓게 쓸 수 있습니다.
  배치와 접힘 상태는 앱을 껐다 켜도 유지됩니다.
- **창 → 패널 배치 초기화**로 처음 배치로 되돌릴 수 있습니다.
- 화면의 강조 색상을 원하는 색으로 바꿀 수 있습니다.
- 모든 단축키를 바꾸거나 기본값으로 되돌릴 수 있습니다.
- 한국어, 영어, 일본어 화면을 지원합니다.
- 새 버전이 나오면 앱에서 바로 확인하고 업데이트할 수 있습니다.

## WiggleWiggleTool 그림 이어하기

WiggleWiggleTool 10에서 저장한 `.wawa` 파일을 **파일 → 열기**로 불러올 수
있습니다. 원본은 건드리지 않고 새 작업으로 열리며, 처음 저장할 때 같은
이름의 `.ugu` 파일을 제안합니다.

두 앱의 표현 방식이 달라 일부 우글거림, 에어브러시, 채워진 모양은 조금
다르게 보일 수 있습니다. 불러오기가 끝나면 바뀌거나 가져오지 못한 항목을
앱이 알려 줍니다.

## 자주 쓰는 단축키

아래는 기본값입니다. **설정 → 단축키**에서 모두 바꿀 수 있습니다.

| 키 | 동작 |
| --- | --- |
| `B` / `E` | 브러시 / 지우개 |
| `L` / `W` / `G` | 영역 선택 / 자동 선택 / 페인트 통 |
| `I` | 스포이드 |
| `P` | 움직임 재생 또는 일시정지 |
| 두 손가락 드래그·핀치·비틀기 | 캔버스 이동·확대/축소·회전 (지원되는 멀티터치 화면) |
| `Space` + 드래그 | 캔버스 이동 |
| `Shift+Space` + 마우스/펜 드래그 | 캔버스 자유 회전 |
| `Shift` + 스크롤 | 캔버스를 5°씩 회전 |
| `-` / `^` | 캔버스를 왼쪽/오른쪽으로 5° 회전 |
| **보기 → 캔버스 회전 → 캔버스 회전 초기화** | 캔버스 회전을 0°로 초기화 |
| 스크롤 | 확대 또는 축소 |
| `Alt` + 클릭 | 그림에서 색상 가져오기 |
| `Alt+Delete` | 선택한 영역을 브러시 색으로 채우기 |
| `Ctrl+T` | 아래쪽 애니메이션 바 접기 또는 펴기 |
| `Ctrl/Cmd+C`, `X`, `V` | 복사 / 잘라내기 / 붙여넣기 |
| `Ctrl+Z` / `Ctrl+Y` | 실행 취소 / 다시 실행 (Windows) |
| `Cmd+Z` / `Cmd+Shift+Z` | 실행 취소 / 다시 실행 (macOS) |
| `Ctrl/Cmd+0` | 캔버스를 창에 맞추기 |
| `Ctrl/Cmd+1` | 실제 픽셀 크기로 보기 |
| `Enter` / `Esc` | 선택한 변경 적용 / 취소 |
| `F1` | 앱 안의 도움말 열기 |

## 설정과 업데이트

툴바의 톱니바퀴 버튼으로 언어, 화면 색상, 그리기 동작, 기본 저장 폴더,
단축키를 바꿀 수 있습니다. Windows에서는 **편집 → 설정**, macOS에서는
**Ugurugu → 설정**에서도 열 수 있습니다.

앱은 실행할 때 새 버전이 있는지 확인합니다. **도움말 → 업데이트 확인**을
누르면 언제든 직접 확인할 수 있습니다.
