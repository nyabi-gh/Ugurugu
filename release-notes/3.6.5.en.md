Ugurugu 3.6.5 fixes six problems found in a review of the code. Ugurugu
3.0.1 to 3.6.4 offer the update by themselves, or you can install it with
the Setup file, disk image or AppImage below.

## Fixed

- Undoing a change to a layer's outline colour put the colour back at once
  as a new step, and the opacity and outline width sliders kept showing
  the value from before the undo. (#204)
- Typing a number of frames such as 100 set it to 2 and 10 on the way,
  which removed the keys and cels past those frames. A value typed in a
  number field is now set when you press Enter or leave the field. (#204)
- A selection moved wholly off the canvas stayed visible where it had
  been, though exports and playback showed it gone. (#204)
- Dragging a layer with the move tool while the animation played was
  called off after a moment, and pressing the play key while drawing lost
  the stroke. (#204)
- A drawing whose fills and selections used the whole 128 MiB a file may
  hold was saved but could not be opened again. (#204)
- Linux: starting the AppImage again, or opening a drawing with it, while
  a window was open did nothing. The open window now comes forward and
  opens the drawing. (#204)
