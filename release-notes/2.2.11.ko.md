## 개선

- 선을 그을 때 화면이 펜을 늦게 따라오거나 끊기던 것을 크게 줄였습니다.
  캔버스를 창의 다른 부분과 따로 화면에 내보내도록 바꿔, 좌표 표시나 브러시
  미리보기, 타임라인이 바뀔 때마다 캔버스 전체를 다시 그리던 일이 없어졌습니다.
  창이 크고 펜을 빠르게 움직일수록 차이가 큽니다.
- 선을 긋는 동안 새로 그린 끝부분만 다시 그리고, 그때마다 화면 전체를
  복사하던 작업도 없앴습니다. 펜이나 마우스를 움직이기만 할 때는 커서만 다시
  그립니다.
- 재생 중에 새 선을 긋기 시작하면 첫 화면을 백그라운드에서 준비해, 펜을 대는
  순간 멈칫하던 것을 줄였습니다. 레이어가 아주 많은 그림에서도 선을 긋기
  시작할 때의 준비가 빨라졌습니다.
- 움직이지 않는 레이어는 한 번만 그려 두고 모든 프레임에서 다시 쓰며, 빈
  레이어는 건너뜁니다. 재생 준비와 내보내기가 빨라졌습니다.
- 저장이 백그라운드에서 진행되어, 큰 프로젝트를 저장하는 동안에도 계속 그릴
  수 있습니다. 저장이 시작된 뒤에 고친 내용은 저장되지 않은 상태로 남습니다.
- 움직이는 GIF와 WebP로 내보낼 때 모든 프레임을 한꺼번에 메모리에 들고 있지
  않아 메모리를 훨씬 적게 씁니다.
- 스포이드, 자동 선택, 채우기 도구를 고른 상태에서는 기준 이미지를 미리
  준비해 두어 클릭할 때 멈칫하지 않습니다.
- 크게 확대하거나 회전한 캔버스를 움직일 때 캔버스 그림자 때문에 느려지고
  메모리를 많이 쓰던 것을 고쳤습니다.
- 필압이 바뀌는 긴 선을 그을 때 이미 그린 부분을 매번 다시 그리지 않습니다.
- Windows에서 Ctrl+Shift+Z로도 다시 실행할 수 있고, Shift+Del, Ctrl+Insert,
  Shift+Insert로 잘라내기, 복사, 붙여넣기를 할 수 있습니다. macOS도 시스템의
  표준 단축키를 모두 받습니다.
- Windows 설치 파일에서 쓰지 않는 약 20MB의 구성요소를 뺐습니다.

## 수정

- 펜의 옆 버튼을 누르면 그리던 선이 취소되던 문제를 수정했습니다.
- Space를 누른 채 화면을 옮기다 펜을 들었다 다시 대면 Space를 누르고 있는데도
  선이 그어지던 문제와, 펜을 화면에서 떼도 커서 링이 남아 있던 문제를
  수정했습니다.
- 우글거림을 끈 상태에서 선을 마치면 우글거린 모습이 화면에 남을 수 있던
  문제를 수정했습니다.
- 이미지나 선택 영역을 이동한 뒤 회전하거나 뒤집는 등 변환을 이어서 하면
  결과가 엉뚱한 위치로 가던 문제를 수정했습니다.
- 클리핑 레이어가 얹힌 레이어를 아래 레이어와 병합하면 그림이 바뀌던 문제를
  수정했습니다. 이런 레이어는 이제 병합할 수 없고, 병합 버튼에 이유가
  표시됩니다.
- 메모리가 부족해 그리기에 실패한 뒤 앱이 멈춰 버리던 문제를 수정했습니다.
- 한국어와 일본어에서 확인·취소 같은 기본 버튼, 색 선택 창, 파일 창이 영어로
  나오던 문제를 수정했습니다.
- 이미지 삽입 목록에 WebP, GIF, TIFF가 있어도 실제로는 열리지 않던 문제를
  수정했습니다. 이제 열 수 있는 형식만 목록에 나옵니다.
- 저장할 때 확장자가 붙어 바뀐 이름의 파일이 이미 있으면 덮어쓸지 묻지 않던
  문제를 수정했습니다.
- Windows에서 인터넷이 끊긴 채 실행 직후 또는 업데이트를 받는 도중에 창을
  닫으면 앱이 뒤에 남아, 다시 실행해도 이미 실행 중이라고만 나오던 문제를
  수정했습니다.

## 보안

- 압축을 풀면 비정상적으로 커지는 데이터를 담은 파일을 열 때, 풀기 전에 정한
  크기를 넘지 않도록 막습니다.
- macOS의 업데이트 구성요소(Sparkle)를 보안 문제가 수정된 2.9.6으로
  올렸습니다.
