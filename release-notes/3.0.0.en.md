Ugurugu 3.0 is a new Windows app, rebuilt from the ground up. It keeps the
2.2.13 tools and layout and installs beside 2.2.13 without touching it.

## Before you install

- **Windows only.** macOS keeps 2.2.13, whose download stays on the
  [v2.2.13 release](https://github.com/nyabi-gh/Ugurugu/releases/tag/v2.2.13).
- **A separate app.** 3.0 installs as "Ugurugu 3" in its own folder, with its
  own settings, recovery files and Start menu entry. 2.x does not update to
  3.0 by itself; you can keep both and remove 2.x whenever you like.
- **Not code-signed.** Windows SmartScreen may say it does not recognize the
  app. Choose **More info** and then **Run anyway**. To check the download,
  compare it with `SHA256SUMS-Windows.txt` on this page.

## New

- A new drawing engine. Playback, zoom and editing stay smooth on large
  canvases and long animations. The canvas and export draw the project with
  the same renderer; only playback while zoomed out draws frames with less
  detail, so that it keeps up.
- A new project format, `.ugurugu`, which Windows opens with Ugurugu 3.
- 2.x projects (`.ugu`) saved with 2.1.0 or later open in 3.0 and are saved
  as `.ugurugu`. The original `.ugu` file is not changed.
- Pixel mode for pixel art, turned on per project in the Edit menu or when
  making a new project: pixel brushes only, no blended edges, transforms and
  image resizing by whole pixels, whole-pixel wobble, a pixel grid and
  enlarged export.
- Projects open in tabs above the canvas, in one window. A project opened
  from File Explorer opens as a new tab of the window already open, and
  starting Ugurugu again brings that window to the front.
- Panels can be moved, grouped into tabs and resized, and the layout is kept.
- Tool presets with their motion settings, saved as `.ugurugu-tools` files.
- Crash reports: if Ugurugu closes unexpectedly, it says so the next time it
  starts and can open the folder of log files to attach to a report. Nothing
  is sent automatically.
- **Help > Check for Updates…** and an automatic check that can be turned off
  in Settings.

## Changed from 2.x

- **Ctrl+T** now transforms the selection with a box on the canvas; the
  animation bar is shown and hidden with **Ctrl+Shift+T**. Shortcuts can be
  changed in Settings.

## Known limitations

- Pen and touch input have been tested with simulated Windows pen and touch
  input. Tablets and drivers differ, so please report any pen or tablet
  problem with the log folder from **Settings > About**.
- Tested on NVIDIA graphics and on the Windows software renderer (WARP).
  If the canvas does not show correctly on other graphics hardware, please
  report it with the diagnostic info from **Settings > About**.
