Ugurugu 3.6.3 tells you when a file dialog cannot be opened, and calls the
theme that follows the system "Same as system". Ugurugu 3.0.1 to 3.6.2
offer the update by themselves, or you can install it with the Setup file
below.

## macOS and Linux

Ugurugu 3 now has a macOS and a Linux version, added to this release after
the Windows one. They have not been tried much with real pen tablets yet;
please tell us if something looks wrong. (#187, #192, #193)

- macOS 14 or later on Apple Silicon: unzip `Ugurugu-3.6.3-macOS-arm64.zip`
  and move `Ugurugu 3.app` to Applications. It has no Apple developer
  signature, so the first time you open it, click Open Anyway at the bottom
  of System Settings → Privacy & Security. It installs beside Ugurugu
  2.2.13.
- Linux x86_64 with glibc 2.35 or later, X11 or Wayland and a Vulkan
  driver: make `Ugurugu-3.6.3-Linux-x64.AppImage` executable and run it.
  It does not register itself for `.ugurugu` files.

Both offer later versions by themselves, as the Windows version does.

## Changed

- The theme choice "Same as Windows" is now "Same as system", and Help
  says "file manager" where it said "File Explorer". (#187)

## Fixed

- When a file dialog could not be opened, nothing happened. Ugurugu now
  says that it could not open the dialog. (#187)
