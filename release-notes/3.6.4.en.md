Ugurugu 3.6.4 comes for macOS as a disk image signed and notarized by
Apple, so it opens without Open Anyway. Windows and Linux have no changes
from 3.6.3. Ugurugu 3.0.1 to 3.6.3 offer the update by themselves, or you
can install it with the Setup file, disk image or AppImage below.

## macOS

- The macOS version now comes as `Ugurugu-3.6.4-macOS-arm64.dmg`, signed
  with an Apple Developer ID and notarized by Apple. Open it and drag
  `Ugurugu 3.app` to Applications; macOS no longer asks you to click Open
  Anyway. Ugurugu 3.6.3 on macOS offers this update by itself. (#200)
