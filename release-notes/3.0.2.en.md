Ugurugu 3.0.2 makes Ugurugu sturdier with files made elsewhere. Ugurugu 3.0.1
offers the update by itself, or you can install it with the Setup file below.

## Fixed

- A damaged or deliberately crafted project could stop the canvas from
  drawing, make an export wait forever, or use gigabytes of memory while
  opening. Projects are now checked for these cases before anything is
  drawn, and such a file is refused with a reason.
- Importing a 2.x project that held more than a 3.0 project can now stops
  as soon as the limit is reached, instead of building the whole project in
  memory first.
- A project whose layers or strokes had reached the highest possible number
  could no longer get new layers or strokes.

## Changed

- A project holds images of up to 64 times 4096 × 4096 pixels in total.
  Inserting an image past that is refused with the data-limit message, like
  inserting past the 128 MiB limit.
