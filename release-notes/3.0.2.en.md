Ugurugu 3.0.2 makes Ugurugu sturdier with files made elsewhere. Ugurugu 3.0.1
offers the update by itself, or you can install it with the Setup file below.

## Fixed

- Picking a colour on the wheel could change it to another one. Pressing
  the square right after using the ring, or the ring right after the square,
  first treated the press as being on the part used before, so the hue or
  the shade jumped (reported in issue #24).
- A damaged or deliberately crafted project could stop the canvas from
  drawing, make an export wait forever, or use gigabytes of memory while
  opening. Projects are now checked for these cases before anything is
  drawn, and such a file is refused with a reason.
- Importing a 2.x project that held more than a 3.0 project can now stops
  as soon as the limit is reached, instead of building the whole project in
  memory first.
- A project whose layers or strokes had reached the highest possible number
  could no longer get new layers or strokes.
- Closing a project's tab while it was being exported left the export in
  progress forever. The export now ends with an error message.
- Pasting a very large image from another app could use several gigabytes
  of memory before it was found too large, and could close Ugurugu. It is
  now refused like inserting a file that large.
- An unexpected error while drawing the canvas for export left that export
  in progress forever, and the canvas stopped updating. The export now ends
  with an error message and the canvas goes on.

## Changed

- Ugurugu opens where its window was last closed, maximized or not, as 2.x
  did. The first time, on a small screen, the window fits the screen instead
  of reaching under the taskbar.
- A project, a 2.x project, an image or a tool preset can be dropped on the
  window to open, insert or import it.
- Options on the command line are no longer taken for a file to open.

- A project holds images of up to 64 times 4096 × 4096 pixels in total.
  Inserting an image past that is refused with the data-limit message, like
  inserting past the 128 MiB limit.
