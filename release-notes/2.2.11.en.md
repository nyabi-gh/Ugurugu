## Improved

- The canvas now keeps up with the pen far better while you draw. It is
  presented separately from the rest of the window, so the pointer
  coordinates, brush previews and timeline no longer make the whole canvas
  redraw every time they change. The larger the window and the faster the
  pen, the bigger the difference.
- While drawing, only the newly drawn end of the stroke is redrawn, and the
  whole screen is no longer copied for each update. Moving the pen or mouse
  without drawing only redraws the cursor.
- Starting a stroke during playback now prepares the first frame in the
  background, so the pen no longer hesitates the moment it touches down.
  Starting a stroke is also faster in pictures with a great many layers.
- Layers that do not move are drawn once and reused in every frame, and empty
  layers are skipped, so playback warms up and exports faster.
- Saving now runs in the background, so you can keep drawing while a large
  project saves. Changes made after a save starts stay marked as unsaved.
- Exporting animated GIF and WebP no longer holds every frame in memory at
  once and uses much less memory.
- With the eyedropper, magic wand or bucket selected, Ugurugu prepares their
  reference image ahead of time, so a click no longer hesitates.
- Moving a canvas that is zoomed far in or rotated is no longer slowed down
  by the canvas shadow, which also used a lot of memory.
- Long strokes with varying pressure no longer redraw the part already drawn
  on every update.
- On Windows, Ctrl+Shift+Z now also redoes, and Shift+Del, Ctrl+Insert and
  Shift+Insert cut, copy and paste. macOS now accepts all of the system's
  standard shortcuts as well.
- The Windows installer no longer includes an unused component of about
  20 MB.

## Fixed

- Pressing the pen's side button no longer cancels the stroke being drawn.
- Lifting the pen while panning with Space held and touching down again no
  longer draws a stroke although Space is still held, and the cursor ring no
  longer stays behind after the pen leaves the screen.
- With wobble turned off, finishing a stroke could leave a wobbled image on
  screen. Fixed.
- Chaining transforms on an image or selection, such as moving and then
  rotating or flipping, could send the result to the wrong place. Fixed.
- Merging a layer that a clipping layer rests on into the layer below changed
  the picture. Such layers can no longer be merged, and the merge button
  explains why.
- Ugurugu no longer freezes after drawing fails for lack of memory.
- In Korean and Japanese, standard buttons such as OK and Cancel, the color
  picker and the file dialogs appeared in English. Fixed.
- Insert Image listed WebP, GIF and TIFF even when they could not be opened.
  The list now shows only the formats that open.
- Saving no longer skips the overwrite question when adding the extension
  turns the name into that of an existing file.
- On Windows, closing the window right after launch while offline, or while
  an update was downloading, left Ugurugu running in the background, and
  relaunching only reported that it was already running. Fixed.

## Security

- Opening a file whose data would expand to an abnormal size is now stopped
  before decompression goes past a set limit.
- The macOS update component (Sparkle) is updated to 2.9.6, which fixes a
  security issue.
