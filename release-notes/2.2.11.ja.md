## 改善

- 線を描くとき、画面がペンに遅れてついてきたり途切れたりするのを大きく減らしました。キャンバスをウィンドウのほかの部分とは別に画面へ出すようにしたため、座標表示やブラシのプレビュー、タイムラインが変わるたびにキャンバス全体を描き直すことがなくなりました。ウィンドウが大きく、ペンを速く動かすほど差が大きくなります。
- 線を描いている間は新しく描いた先端だけを描き直し、そのたびに画面全体をコピーする処理もなくしました。描かずにペンやマウスを動かすだけのときは、カーソルだけを描き直します。
- 再生中に新しい線を描き始めると最初の画面をバックグラウンドで準備するため、ペンを置いた瞬間に引っかかるのを減らしました。レイヤーがとても多い絵でも、描き始めの準備が速くなりました。
- 動かないレイヤーは一度だけ描いてすべてのフレームで使い回し、空のレイヤーは飛ばします。再生の準備と書き出しが速くなりました。
- 保存をバックグラウンドで行うようにしたため、大きなプロジェクトを保存している間も描き続けられます。保存が始まった後の変更は未保存のまま残ります。
- 動く GIF と WebP の書き出しで、すべてのフレームを一度にメモリに持たなくなり、メモリの使用量が大きく減りました。
- スポイト、自動選択、塗りつぶしを選んでいる間は基準になる画像を前もって準備しておくため、クリックしたときに引っかかりません。
- 大きく拡大したり回転したりしたキャンバスを動かすとき、キャンバスの影のせいで遅くなり、メモリも多く使っていた問題を直しました。
- 筆圧が変わる長い線を描くとき、描き終えた部分を毎回描き直さなくなりました。
- Windows で Ctrl+Shift+Z でもやり直しができ、Shift+Del、Ctrl+Insert、Shift+Insert で切り取り、コピー、貼り付けができます。macOS でもシステムの標準ショートカットをすべて受け付けます。
- Windows のインストーラーから、使っていない約 20MB の構成要素を外しました。

## 修正

- ペンのサイドボタンを押すと描いている線が取り消される問題を修正しました。
- Space を押したまま画面を動かしている途中でペンを離して再び置くと、Space を押しているのに線が引かれる問題と、ペンを画面から離してもカーソルの輪が残る問題を修正しました。
- ゆらぎをオフにした状態で線を引き終えると、ゆらいだ見た目が画面に残ることがある問題を修正しました。
- 画像や選択範囲を移動してから回転や反転を続けると、結果がおかしな位置に行く問題を修正しました。
- クリッピングレイヤーが乗っているレイヤーを下のレイヤーと結合すると絵が変わる問題を修正しました。このようなレイヤーは結合できなくなり、結合ボタンに理由が表示されます。
- メモリ不足で描画に失敗した後、アプリが固まってしまう問題を修正しました。
- 韓国語と日本語で、OK やキャンセルなどの標準ボタン、色の選択、ファイルの画面が英語で表示される問題を修正しました。
- 画像の挿入の一覧に WebP、GIF、TIFF があっても実際には開けない問題を修正しました。開ける形式だけが一覧に出るようになりました。
- 保存時に拡張子が付いて名前が変わり、その名前のファイルがすでにあるときに、上書きの確認が出ない問題を修正しました。
- Windows でインターネットにつながっていない状態で起動直後に、またはアップデートのダウンロード中にウィンドウを閉じると、アプリが裏に残り、もう一度起動しても「すでに実行中」とだけ表示される問題を修正しました。

## セキュリティ

- 展開すると異常に大きくなるデータを含むファイルを開くとき、決められた大きさを超えて展開されないようにしました。
- macOS のアップデート用の構成要素（Sparkle）を、セキュリティの問題が修正された 2.9.6 に更新しました。
