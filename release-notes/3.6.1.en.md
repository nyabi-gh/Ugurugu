Ugurugu 3.6.1 lets the brush, the eraser and the shape tools go up to
512 px, as asked in #157. Ugurugu 3.0.1 to 3.6.0 offer the update by
themselves, or you can install it with the Setup file below.

## Improved

- The brush, the eraser and the shape tools go up to 512 px, from 128 px,
  for large canvases. The size slider now gives small and large sizes the
  same room: each doubling takes the same length. `[` and `]` step on
  through 160, 192, 224, 256, 320, 384, 448 and 512. Documents stay
  readable by earlier versions. (#157, #177)
