Ugurugu 3.6.2 fixes the lag of brushes wider than 128 px. Ugurugu 3.0.1
to 3.6.1 offer the update by themselves, or you can install it with the
Setup file below.

## Fixed

- A brush wider than 128 px fell behind the pointer while drawing, the
  more the wider it was, and kept the processor busy. The stroke being
  drawn is now updated once per screen frame instead of once per pointer
  sample. (#157)
